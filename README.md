# Temporal Convolutional Networks (TCN)

## Project Overview

An independent PyTorch implementation and evaluation of
Temporal Convolutional Networks for sequence modeling.

## Reference Paper

An Empirical Evaluation of Generic Convolutional and
Recurrent Networks for Sequence Modeling

Authors: Shaojie Bai, J. Zico Kolter, Vladlen Koltun

Paper: https://arxiv.org/abs/1803.01271

Reference implementation:
https://github.com/locuslab/TCN
